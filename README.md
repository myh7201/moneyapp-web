# moneyapp-web

記帳電腦版網站。

## v254 桌面功能

預設 125% 顯示大小；網站內直接輸入金額，分類每行四格。
定期記帳使用工作區卡片，帳戶頁包含貨幣帳戶及往來對象。
收支分析支援週／月／年／自訂期間、進階篩選、分類／子分類排行、圓環、可點擊的棒形圖與折線圖、日曆及資金移動。
預算保留手機版的每日及分類額度，返回原本桌面頁面。

## GitHub 同步

設定一次後加密記住此裝置的憑證，重開後自動連接。已儲存內容不提供查看或複製，可更換、暫停或忘記。清除網站資料後須重新設定。
帳目只同步至你指定的私人資料儲存庫；這個網站儲存庫不包含帳目、Token 或同步密碼。兩端同時修改時保留兩份並請你選擇。

## v255 一致性修正

首頁資產按帳簿貨幣計算，與手機首頁一致，包含應收款並另列負債。
三張首頁卡片均可進入詳情並返回主頁。日期支援連續退格，不再卡住分隔線，移除日期藍框。
圖表日期固定顯示在當天上方，取消後移除提示，不再出現整條選取陰影。
